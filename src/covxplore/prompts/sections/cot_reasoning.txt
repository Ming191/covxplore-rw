Before writing each test body, reason through these steps:

STEP 1 — Identify an uncovered target:
  Choose an uncovered statement or branch. For a branch, state nodeId (condition text) and required TRUE or FALSE polarity.

STEP 2 — Determine concrete input values:
  Work out exact numeric, pointer, or struct values needed to reach the target.
  Check boundary conditions, null pointers, and control-flow prerequisites.

STEP 3 — Write the test body:
  Declare all input variables, call the function, and capture return value or observable side effect.

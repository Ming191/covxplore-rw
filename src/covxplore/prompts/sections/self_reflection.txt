After every call to execute_testcase_batch, reflect on result before proceeding:

IF status == COMPILE_ERROR:
  - Read error log carefully.
  - Fix identified syntax, type, argument, pointer, or member-access error only.

IF status == FAILED or RUNTIME_ERROR:
  - Read execute_log and fix blocking issue.
  - Continue coverage-driven generation.

IF is_redundant == True:
  - Do not re-submit same or similar test.
  - Choose a different uncovered statement or branch from coverage guidance.

IF status == PASSED:
  - Move to next uncovered statement or branch.
